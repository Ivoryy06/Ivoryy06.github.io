Small Linux programs I wrote because I needed them, and kept using.

BlackboxD

A flight recorder for your computer. It writes down which windows you used and for how long, so you can see where your day went without slowing the machine down.

Python · Go · Rust · Lua

git clone https://github.com/Ivoryy06/BlackboxD.git
cd BlackboxD && chmod +x install.sh && ./install.sh
open the dashboardsource

cardnuke

Wipe, back up, check and restore SD cards and USB drives from one terminal. It asks before anything destructive, and its speed and health checks never touch your files.

C++ · Linux

git clone https://github.com/Ivoryy06/cardnuke.git
cd cardnuke && make && sudo ./cardnuke list
source

mend

System backup, health checks and rollback for Linux, with a terminal interface. It's built to work with BlackboxD: it can hold a backup until you've stepped away, and it knows what you were doing when something broke.

Python · systemd · rsync

source: not public yet

mend and BlackboxD are meant to be used together. One records what you do, the other looks after the machine around it.
